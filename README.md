# Арифметический интерпретатор

Калькулятор арифметических выражений с поддержкой математических функций и побитовых операций. Реализован на языке Python с применением метода рекурсивного спуска для синтаксического анализа.

## Функциональные возможности

- Базовые арифметические операции: сложение, вычитание, умножение, деление
- Побитовое ИЛИ (`|`)
- Функция вычисления минимума из списка чисел: `min(x, y, ...)`
- Унарный минус для отрицательных чисел и выражений
- Скобки для изменения приоритета операций
- Поддержка целых и дробных чисел
- Два режима работы: консольный и графический интерфейс
- Валидация входных выражений с информативными сообщениями об ошибках

## Структура проекта

```
INFIT_Lab1_Calculator/
├── Backend/
│   ├── lexer.py          # Лексический анализатор (токенизация)
│   └── parser.py         # Синтаксический анализатор (парсер)
── Frontend/
│   └── gui.py            # Графический интерфейс пользователя
├── main_console.py       # Точка входа для консольного режима
└──main_gui.py            # Точка входа для графического режима
```

## Запуск приложения

### Консольный режим

```bash
python main_console.py
```

После запуска программа ожидает ввод выражения в командной строке.

### Графический интерфейс

```bash
python main_gui.py
```

Откроется окно приложения с полем ввода, кнопками операций и областью вывода результата.

## Примеры использования

```
2 + 3 * 4                 Результат: 14
(2 + 3) * 4               Результат: 20
min(5, 2, 8)              Результат: 2
min(2*3, 4+5)             Результат: 6
5 | 3                     Результат: 7
-(2 + 3) * 4              Результат: -20
min(1, min(2, 3))         Результат: 1
2 + 3 * (4 - 1) / 2       Результат: 6.5
```

## Архитектура системы

**Backend** — отвечает за обработку выражений:
- `Lexer` выполняет лексический анализ: проверяет допустимость символов, выявляет синтаксические ошибки и преобразует строку в последовательность токенов.
- `Parser` выполняет синтаксический анализ и вычисление результата методом рекурсивного спуска.

**Frontend** — отвечает за взаимодействие с пользователем:
- Консольный интерфейс через стандартный ввод-вывод.
- Графический интерфейс на базе библиотеки Tkinter с поддержкой ввода с клавиатуры и кликов по кнопкам.

## Принцип работы парсера

Синтаксический анализатор реализован методом рекурсивного спуска с четырьмя уровнями приоритета операций:

```
parse_expression   — побитовое ИЛИ (|)
    ↓
parse_additive     — сложение и вычитание (+, -)
    ↓
parse_term         — умножение и деление (*, /)
    ↓
parse_factor       — числа, скобки, унарный минус, функция min()
```

## Используемые технологии

- Язык программирования: Python 3.10+
- Стандартная библиотека: Tkinter, ttk (графический интерфейс)
- Метод синтаксического анализа: рекурсивный спуск
